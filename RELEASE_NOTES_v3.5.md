# Z's Save Archive v3.5 — Starter Tags and Save Origin

- Adds a starter-tag picker inside the existing save inspector; preserves manually entered tags.
- Adds origin type, source/creator, optional HTTP(S) URL, and origin notes.
- Migrates old archive databases by adding optional columns, without changing save data.
- Includes origin details in new ZIP backup manifests; public site export remains unchanged.
- Source URL is validated as HTTP(S), forbids embedded credentials; provenance is not independently verified.
- All previous build scripts, assets, FTP, ISO, PKG, homebrew and publishing modules are retained.
